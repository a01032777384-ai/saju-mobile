# 별담 · 모바일 사주

접속 URL: https://gabkeunc-sys.github.io/saju-mobile/

HTML/CSS/JavaScript 기반 GitHub Pages 사이트. Supabase Auth 이메일/비밀번호 인증을 사용합니다.

## 사용 방법
첫 화면 → 시작 → 회원가입/로그인 → 생년월일과 출생 시각 입력 → 결과. 음력은 한국 음력이며 윤달은 실제 윤달일 때만 선택합니다. 출생 시각을 모르면 체크박스를 선택합니다. 로그인 세션은 Supabase SDK가 유지하며 비밀번호는 직접 저장하지 않습니다. 입력과 결과는 메모리에만 보관하고 새로고침 시 제거합니다.

## 계산 기준
- 양력 환산 1900-01-01~2050-12-31. 한국 출생, 전 기간 UTC+9 고정.
- 과거 표준시 변경/서머타임과 진태양시 보정은 하지 않습니다. 해당 출생기록은 먼저 UTC+9로 환산해야 합니다.
- 한국 음력 변환: korean-lunar-calendar 0.4.0. 중국 음력과 혼용하지 않습니다.
- 절기: lunar-javascript 1.7.7. UTC+8 기준 절기와 비교하기 위해 입력 UTC+9 시각을 1시간 앞당겨 연주/월주를 계산합니다. 일주/시주에는 이 시차를 적용하지 않습니다.
- 연주: 입춘 교입 순간. 월주: 입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한의 교입 순간.
- 일주: 한국 표준시 00:00 경계. 시주: 자시 23:00~00:59, 축시 01:00~02:59 등. 시주의 천간은 해당 날짜의 일간 기준으로 계산하며, 23시를 다음 날로 보는 학파와 다를 수 있습니다.
- 시각 입력의 초는 00초입니다. 절기 경계 분의 출생시각 정확도가 부족하면 결과가 달라질 수 있습니다.
- 시각 모름: 시주를 계산하지 않습니다. 해당 날짜 시작과 끝의 연주/월주가 다르면 그 기둥도 미확정으로 표시합니다.
- 오행: 확정된 천간/지지 각 글자의 대표 오행을 1개씩 집계. 지장간·월령 가중치·강약·용신은 포함하지 않습니다. 미확정 기둥은 제외합니다.
- 일간 및 오행 개수에 연결된 고정 규칙의 해석입니다. 외부 AI API/랜덤 결과를 사용하지 않습니다. 교육·오락용이며 과학적 예측이 아닙니다.

## 인증과 개인정보
프로젝트 `saju-mobile` (서울): `tngyafnlufaaexiqvgdi`. 프런트에는 공개 publishable 키만 사용합니다. 사용자 테이블은 없으며 생년월일이나 결과를 서버로 전송하지 않습니다. 인증용 이메일/비밀번호는 Supabase Auth로만 전송합니다. 서버에 사주 데이터를 저장하지 않으므로 별도의 RLS 대상 테이블이 없습니다. 정적 소스는 공개되며 화면 보호는 로그인 상태/사용자 조회로 처리합니다. 향후 서버 데이터 기능을 추가할 때는 반드시 서버측 인가/RLS가 필요합니다.

## 배포
루트의 index.html을 GitHub Pages main/(root)로 배포합니다. 리소스는 상대경로, 화면은 hash 라우팅을 사용합니다. SDK는 jsDelivr의 @supabase/supabase-js 2.49.1 고정 버전을 사용합니다.

### 실습용 회원가입 간소화
이메일 확인 링크 없이 가입 즉시 자동 로그인합니다. 공개 anon JWT로 호출하는 practice-signup Edge Function이 서버 내 SUPABASE_SERVICE_ROLE_KEY를 사용하여 신규 Auth 사용자만 email_confirm=true로 생성합니다. 관리자 키는 소스/브라우저로 전달되지 않습니다. 기존 사용자의 비밀번호나 확인 상태는 변경하지 않습니다. 이후 로그인/세션/로그아웃은 표준 Supabase Auth SDK가 처리합니다. 이 실습 경로는 기본 이메일 확인 설정과 독립적이며, 프로덕션 전환 시 일반 확인 메일 흐름과 가입 요청 제한을 재설계하세요.

Site URL/Redirect URL의 관리 설정은 변경되지 않았습니다. 현재 비밀번호 로그인 흐름은 이메일 리디렉션을 사용하지 않습니다.
