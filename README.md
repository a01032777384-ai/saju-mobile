# 별담 운세 · 오늘부터 한 해까지

접속 URL: https://a01032777384-ai.github.io/saju-mobile/

HTML/CSS/JavaScript 기반 GitHub Pages 사이트. Supabase Auth 이메일/비밀번호 인증을 사용합니다.

## 사용 방법
첫 화면 → 시작 → 회원가입/로그인 → 생년월일과 출생 시각 입력 → 일간·월간·연간 운세. 음력은 한국 음력이며 윤달은 실제 윤달일 때만 선택합니다. 출생 시각을 모르면 체크박스를 선택합니다. 로그인 세션은 Supabase SDK가 유지하며 비밀번호는 직접 저장하지 않습니다. 입력과 결과는 메모리에만 보관하고 새로고침 시 제거합니다.

## 계산 기준
- 양력 환산 1900-01-01~2050-12-31. 한국 출생, 전 기간 UTC+9 고정.
- 과거 표준시 변경/서머타임과 진태양시 보정은 하지 않습니다. 해당 출생기록은 먼저 UTC+9로 환산해야 합니다.
- 한국 음력 변환: korean-lunar-calendar 0.4.0. 중국 음력과 혼용하지 않습니다.
- 절기: lunar-javascript 1.7.7. UTC+8 기준 절기와 비교하기 위해 입력 UTC+9 시각을 1시간 앞당겨 연주/월주를 계산합니다. 일주/시주에는 이 시차를 적용하지 않습니다.
- 연주: 입춘 교입 순간. 월주: 입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한의 교입 순간.
- 일주: 한국 표준시 00:00 경계. 시주: 자시 23:00~00:59, 축시 01:00~02:59 등. 시주의 천간은 해당 날짜의 일간 기준으로 계산하며, 23시를 다음 날로 보는 학파와 다를 수 있습니다.
- 시각 입력의 초는 00초입니다. 절기 경계 분의 출생시각 정확도가 부족하면 결과가 달라질 수 있습니다.
- 시각 모름: 시주를 계산하지 않습니다. 해당 날짜 시작과 끝의 연주/월주가 다르면 그 기둥도 미확정으로 표시합니다.
- 오행: 확정된 천간/지지 각 글자의 대표 오행을 1개씩 집계. 지장간·월령 가중치·강약·용신은 포함하지 않습니다. 미확정 기둥은 제외합니다.
- 일간 및 오행 개수에 연결된 고정 규칙의 해석입니다. 외부 AI API/랜덤 결과를 사용하지 않습니다. 교육·오락용이며 과학적 예측이 아닙니다.

## 인증과 개인정보
기존 소스에 설정된 프로젝트(소유 이메일·리전 재확인 불가): `tngyafnlufaaexiqvgdi`. 프런트에는 공개 publishable 키만 사용합니다. 사용자 테이블은 없으며 생년월일이나 결과를 서버로 전송하지 않습니다. 인증용 이메일/비밀번호는 Supabase Auth로만 전송합니다. 서버에 사주 데이터를 저장하지 않으므로 별도의 RLS 대상 테이블이 없습니다. 정적 소스는 공개되며 화면 보호는 로그인 상태/사용자 조회로 처리합니다. 향후 서버 데이터 기능을 추가할 때는 반드시 서버측 인가/RLS가 필요합니다.

## 배포
루트의 index.html을 GitHub Pages main/(root)로 배포합니다. 리소스는 상대경로, 화면은 hash 라우팅을 사용합니다. SDK는 jsDelivr의 @supabase/supabase-js 2.49.1 고정 버전을 사용합니다.

### 인증 연결 상태 (2026-10-30)
기존 Supabase 프로젝트의 공개 키로 실제 이메일/비밀번호 로그인을 연결합니다.
기존 회원가입 Edge Function은 원 사이트 Origin만 허용하고 일반 가입에는 이메일 확인이 필요합니다.
따라서 새 배포 주소의 즉시 가입은 현재 준비 중으로 표시하며 가짜 인증을 제공하지 않습니다.
`supabase/functions/practice-signup/index.ts`에 두 Pages Origin을 허용하는 변경본을 준비했지만 서버 배포는 미완료입니다.
Supabase 관리 연결 후 이 함수를 배포하고 새 Origin의 가입을 검증한 다음 `config.mjs`의 signupMode를 `practice`로 바꿉니다.
기존 프로젝트의 전역 이메일 확인 정책과 기존 사용자 계정은 변경하지 않았습니다.
출생 데이터 테이블을 만들지 않으므로 이 앱에는 RLS 대상 데이터 테이블이 없습니다.

## 운세 리포트 v2.0
사이트를 일간·월간·연간 운세 중심으로 개편했습니다. 출생 명식과 조회 간지를 실제 계산한 뒤 고정된 편집 규칙으로 해석합니다. 외부 유료 AI나 랜덤 운세 점수를 사용하지 않습니다.

- 기본 조회일: Asia/Seoul의 오늘. 지원 조회일 1900-01-01~2050-12-31.
- 일간: 조회일 정오 일주와 출생 일간의 십신. 09·13·19시 시주를 시간대별 보조 포인트로 제시.
- 월간: 선택한 양력 월 15일 정오 월주가 대표값. 각 주간 구간 가운데 날짜 정오의 일진을 체크포인트로 사용. 같은 운세가 구간 전체에 적용된다는 뜻이 아님.
- 연간: 선택 연도 7월 1일 정오 연주가 대표값. 각 월 15일 정오 월주로 12개월 흐름을 비교.
- 연주/월주는 입춘·절기 교입에 따라 바뀌므로 양력 연월 전체에 동일한 간지를 부여하지 않음. 기간 중 매일 정오 관찰에서 변화가 처음 확인된 날을 별도 표시. 이 관찰 날짜는 정확한 절입 시각표가 아님.
- 천간 십신: 일간과 조회 천간의 오행 생극 및 음양을 비교. 지지는 대표 오행의 생극 관계만 보조 해석하며 지장간의 십신 전체로 표시하지 않음.
- 출생 지지와 조회 지지의 육합·충·동일 반복을 개별 기록. 합화 성립·길흉 사건을 단정하지 않음.
- 5분야(일·학업, 금전·소비, 연애·관계, 대인·협업, 생활·컨디션)에 각 5문단: 기본 해석, 적용, 기간별 계획, 구체 사례, 주의점을 제공. 본문은 5개 오행 관계 계열과 10개 십신 설명, 명식 구성, 조회 시점에 따라 조합됨.
- 체크리스트는 화면 메모리에만 유지. 본문 복사는 사용자 버튼 클릭 시 클립보드에 기록.
- 이 콘텐츠는 전통 상징을 바탕으로 작성한 자기점검용 교육·오락 콘텐츠. 확률·수익·진단·상대의 마음을 예측하지 않음. 대운·신강신약·용신·신살을 계산한 종합 명리 감정이 아님.
